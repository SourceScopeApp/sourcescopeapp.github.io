Privacy Policy

Last updated: June 12, 2026

SourceScope is a Chrome extension that helps users inspect citations, references, archives, and local ratings related to Wikipedia articles and user-triggered reference checks.

Local-first storage

SourceScope stores saved reports, saved sources, projects, Source Packs, settings, and local workflow data in the user’s browser storage. This information is used to provide the extension’s research workflow features.

Website content and source checks

SourceScope may read page content, citation text, references, links, page titles, and URLs from supported pages so it can provide citation coverage, Source Health, source lead, archive recovery, export, and research organization features.

User-triggered external requests

Some features may contact public metadata, archive, or page sources when the user chooses to use them. These may include services such as Wikipedia, Internet Archive, Crossref, PubMed, and arXiv for reference metadata checks, archive recovery, and source inspection.

Accounts and payments

The free extension can be used without creating a SourceScope account. Paid features are processed by third-party payment providers ExtensionPay and Stripe. SourceScope does not directly collect or store credit card numbers. Payment providers may process payment details, purchase status, subscription status, and the email address used for payment or Pro login.

Optional feedback

If you choose to submit feedback through the SourceScope website, the form may send your selected reasons, written details, extension version, page URL, submission time, and basic browser user-agent information to the configured feedback form provider. Do not include passwords, card numbers, or sensitive personal information in feedback.

Chrome Web Store Limited Use

SourceScope's use and transfer of information received from Chrome APIs, supported web pages, and user-triggered checks complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. SourceScope uses this information only to provide or improve its source-checking, archive-recovery, research-organization, export, payment, support, and feedback features.

SourceScope does not sell user data, does not use user data for personalized advertising, does not transfer user data to advertising platforms or data brokers, and does not use user data to determine creditworthiness or for lending purposes.

Support

For privacy questions or support, contact SourceScope@pm.me.
